# 桌面宠物项目 - 开发计划

## 架构方案

**方案A: 边缘设备 + 网关转发** (当前采用)

```
K230 (边缘设备)                    PC/服务器 (网关)
┌─────────────────┐               ┌─────────────────────────┐
│ • 摄像头采集     │               │ • HTTP服务器            │
│ • 麦克风录音     │  HTTP POST   │ • ASR语音识别           │
│ • 本地AI检测     │ ──────────▶  │ • LLM大模型(阿里通义)   │
│ • 表情渲染      │               │ • TTS语音合成           │
│ • 音频播放      │  ◀────────── │ • 图像理解              │
└─────────────────┘   HTTP响应    └─────────────────────────┘
```

**为什么选这个方案:**
- K230不支持TLS/WSS，无法直接对接云API
- HTTP简单可靠，内网无需加密
- 网关端自由度高，方便调试和切换模型
